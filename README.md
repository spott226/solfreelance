🚀 SolFreelance — Trustless Freelancing on Solana

“No estamos eliminando la confianza. La estamos reemplazando por código.”

🧠 The Problem

Freelancing today is broken.

Clients don’t trust freelancers to deliver
Freelancers don’t trust clients to pay
Platforms act as intermediaries and charge high fees

👉 The entire system depends on trust between strangers.

💡 The Solution

SolFreelance introduces a trustless escrow system powered by Solana.

Instead of trusting people, users trust the code.

💰 Client locks payment in a smart contract
🤝 Freelancer deposits a commitment (skin in the game)
🔓 Payment is only released when the client approves
⚡ No intermediaries, no commissions
🔥 Key Innovation

Unlike traditional escrow platforms:

👉 Freelancers must deposit a commitment amount to apply.

This creates:

Higher quality applicants
Real intent to complete the job
Bilateral accountability
⚙️ How It Works
Client creates a project
→ Funds are locked in a smart contract
Freelancers apply
→ Each deposits a commitment
Client selects freelancer
→ Project is assigned
Non-selected freelancers get refunded
Freelancer completes the work
Client releases payment
→ Funds go directly to freelancer
🔐 Security
Funds are held in a Program Derived Address (PDA)
No centralized custody
Smart contract enforces:
Valid amounts
No duplicate applications
No double release
Only client can release funds
